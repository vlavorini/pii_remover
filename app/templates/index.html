Ingestion

              
    
                
  1. Upload guard: extension + size validation, streaming write

Processing

              
    
                
  1. Validator layer: regex + checksums (IBAN mod-97, Luhn, codice fiscale)
    2. 
                
  2. Detector agent enumerates PII spans
    3. 
                
  3. Critic agent finds misses / false positives, sends feedback
    4. 
                
  4. Loop until agreement (max {{ config.maxCriticRounds }} rounds)
    5. 
                
  5. Masker agent applies the plan, verified against leaks
    6. 
                
  6. Deterministic masking fallback (guaranteed)
    7. 
              

            

            
→

            

              
Output

              
    
                
  1. Cleaned text with stable pseudonyms
    2. 
                
  2. PII-free audit metadata
    3. 
                
  3. Encrypted artifacts, {{ config.retentionMinutes }} min retention
    4. 
              

            

          

          

            
Privacy: TLS is terminated by the reverse proxy. Artifacts are
              encrypted at rest (Fernet / AES-128-CBC + HMAC) and the raw upload is deleted as soon as
              the job finishes. Pseudonyms are keyed HMAC-SHA256, so they are not reversible.
              No personal data is written to logs.

            
Models: every call is OpenAI-compatible and fully configured from
              .env (OPENAI_BASE_URL, OPENAI_API_KEY,
              VISION_MODEL, TEXT_MODEL). Prompts live in
              app/processing/prompts/*.md.
